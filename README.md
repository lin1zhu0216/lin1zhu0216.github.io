# lin1zhu0216.github.io

Personal academic homepage built with React, TypeScript, and Vite.

Website: https://lin1zhu0216.github.io/

## Deployment

The GitHub repository must be named `lin1zhu0216.github.io` and owned by
`lin1zhu0216`. In the repository's Settings > Pages, select GitHub Actions as
the publishing source. Pushing to `main` triggers `.github/workflows/deploy.yml`,
which builds the site and deploys `dist` to GitHub Pages.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
